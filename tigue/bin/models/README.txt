Tigue - Custom Models

Place model folders here. Each model gets its own folder:

  models\
    YourModelName\
      source\
        YourModelName.obj   (or .fbx)
      textures\
        texture.png         (any .png .jpg .jpeg .tga .bmp)

The model name shown in the dropdown is the folder name.
Flat .obj/.fbx files in the models\ folder also work (no texture).
